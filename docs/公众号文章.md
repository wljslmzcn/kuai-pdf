## 功能有多强大？

### 📄 页面操作

- **PDF拆分**：按页码范围拆分，或者每N页拆分成一个文件
- **PDF合并**：多个PDF一键合并，支持拖拽排序
- **页面旋转**：90°、180°、270° 任意旋转
- **页面删除/提取**：批量删除或提取指定页面
- **页面重排**：自定义页面顺序

### 🔄 格式转换

- **图片转PDF**：支持PNG、JPG、BMP，一键生成PDF
- **PDF转文本**：提取文档中的文字内容
- **PDF转图片**：将PDF页面导出为图片

### 💧 水印功能

- **文字水印**：自定义内容、颜色、大小、透明度、角度
- **图片水印**：用自己的Logo作为水印
- **满屏水印**：防盗用必备

### 🔐 加密解密

- **PDF加密**：设置打开密码，RC4 128位加密
- **PDF解密**：输入密码即可解除
- **元数据修改**：修改标题、作者等信息

### 📦 更多功能

- **PDF压缩**：三档压缩可选，最高可压缩80%
- **PDF预览**：内置预览，无需外部阅读器
- **批量处理**：批量压缩、批量加密
- **操作日志**：所有操作都有记录

## 技术实现

这款工具的技术栈：

- **前端**：Vue 3 + TypeScript + Element Plus
- **后端**：Rust + Tauri 2
- **PDF处理**：lopdf + image

选择 Tauri 而不是 Electron，是因为：

1. **体积小** —— 安装包只有 5MB，Electron 动辄 100MB+
2. **性能好** —— Rust 后端，处理速度快
3. **内存占用低** —— 不会像 Electron 那样吃内存
